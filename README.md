# JSKY Weekly Crew Planner

Mobile-first offline PWA for weekly B737 crew planning.

## GitHub Pages deployment
1. Upload all files in this package to the repository root.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / (root) → Save.
5. Open the GitHub Pages HTTPS address.

Important: upload `sw.js`, `manifest.webmanifest`, and all icon PNG files together with `index.html`.
